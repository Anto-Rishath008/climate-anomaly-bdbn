## 🏃‍♂️ **Quick Start**

### 1. **Backend Setup**
```bash
# Install Python dependencies
pip install -r requirements.txt
pip install -r requirements-api.txt

# Run Flask API
python climate-model-api.py
```

### 2. **Frontend Setup**
```bash
# Navigate to webapp directory
cd climate-anomaly-webapp

# Install dependencies
npm install

# Start development server
npm start
```

### 3. **ML Pipeline**
```bash
# Run comprehensive system
python comprehensive_climate_anomaly_system.py

# Run 90% accuracy demo
python final_90_demo.py
```
